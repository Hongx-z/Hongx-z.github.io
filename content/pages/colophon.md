## The type

Serif for reading, sans for chrome. The body text is set in the serif stack
your operating system already ships — Iowan Old Style if you are on a Mac,
Palatino if you are on Windows — because a personal site should load like a
page, not like an application. No webfonts are downloaded.

## The stack

Everything here is a file. The articles are Markdown files, the films are
Markdown files, this page is a Markdown file. A static-site builder turns the
whole thing into plain HTML once per publish, and GitHub Pages serves the
result for free. There is no server of mine anywhere in this chain, no
database, no tracking, no analytics. If the site is down, the repository
still has every word.

## The quiet features

- **Sound.** If a small "Sound" control sits in the corner of your screen, a
  piece of background music is on offer. It is off by default, and it stays
  off until you switch it on yourself.
- **The guestbook.** Comments live in the GitHub Discussions of this
  repository, which means every note left here is one I can read and answer
  from the same place the site itself is kept.
- **The clock.** The footer keeps the time where I am, which is the closest
  the web gets to knowing when a letter was written.
- **The glyph.** At the far end of the footer sits a small ❋, and it is not
  always there: every so often it goes quiet for a second and then comes
  back. If you click it, the same thing happens to the page — every word
  fades, and what is left is a blank sheet of paper. Click anywhere and it
  all returns, exactly as it was. Nothing is saved and nothing is lost; a
  page that can be emptied and refilled is a page you can trust.

## One secret

There is one line on this site that does not appear on any page. It shows
itself only to readers who type the old code — ↑ ↑ ↓ ↓ ← → ← → B A — on
any page. It is not much. It is just that some things are only for the
people who go looking.
